AWS provides scalable cloud services for deploying applications, storing data, managing networks, and monitoring infrastructure.

Amazon EC2
Provides virtual servers for running applications.
Amazon S3
Provides object storage for files, backups, and data.
AWS IAM
Manages users, roles, policies, and permissions.
Amazon VPC
Provides a logically isolated virtual network.
Amazon RDS
Provides managed relational databases.
AWS Lambda
Runs code in response to events without managing servers.

Public Cloud
Private Cloud
Hybrid Cloud


Service Models
IaaS — Infrastructure as a Service
PaaS — Platform as a Service
